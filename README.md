A calibrated minute-by-minute forecaster for the Yes prices of Polymarket's "Next CEO of NVIDIA?" markets: persistence for the median, and a blend of each market's own recent empirical change quantiles with a per-market Gaussian spread for the intervals.

## Run it

```sh
mkdir -p out && MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
